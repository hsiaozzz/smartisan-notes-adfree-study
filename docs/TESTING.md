## 调试过程中遇到的问题

1. 初始安装被设备保护拒绝；调整设备安装保护后重试成功。
2. 改包名后特殊 Provider authority 与官方原版冲突；修改为测试包唯一地址后完成安装。
3. 代码中写死的原版 Provider 地址导致权限错误；同步修改 Manifest、代码和资源引用后，本地数据功能恢复。
4. 设置按钮的隐式 Intent 在两包并存时打开系统选择器；指定测试包后修复。
5. 主页书本按钮的隐式链接同样不能正确打开知识库页面；改为显式指定自身的 `RAGMainActivity` 后，两次进入通过。

## 结论的范围

仅验证以上设备和场景。广告 SDK 类、资源和部分后台组件仍保留，本次改造禁用已定位的初始化及广告展示入口。

日志中仍存在测试包账号类型注册的 `SecurityException` 和后台 `UrlUtils` 类初始化告警，未影响已测本地功能。云同步、登录、会员、AI、知识库写入、分享、推送和支付未验证。广场列表能加载不等于云端功能全部可用。
